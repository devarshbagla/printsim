printsim

3D print simulator

The fanciest loading bar for your 3D prints.

Load the file you're printing, hit start when your printer does, and watch it build layer by layer from anywhere.

Runs entirely in your browser. Your file never leaves this device.

New here? Here's the deal

Lab printers like the Prusa MINI+ aren't on the network, so once you hit print, the only way to check on it is to walk back. printsim is a stand-in: give it the same file you gave the printer, tap Start when the printer starts, and it rebuilds the print in 3D in real time, with how long is left and when it'll be done.

  • Live 3D buildThe printer moves and the layers stack up as they print, from your dorm or class.
  • Timelapse firstScrub or play the whole print at up to 1000× before you commit an 8 hour print.
  • Spaghetti checkForgot supports? It flags what'll droop or fall, and shows it happening.
  • Close the tab, it's fineIt remembers the print. Come back later and it picks up where the printer should be.
  1. Load the same file you sent to the printer
  2. Start the sim the moment you press print
  3. Resync any time by typing the % on the printer's screen

Tuned for the Prusa MINI / MINI+ using Prusa's own firmware numbers. Other printers get a generic profile. Timing is an estimate, not a live feed.
